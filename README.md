# 3. 중앙동아리 소개
경북대학교 중앙동아리는 경북대학교 총동아리연합회를 중심으로 다양한 분야의 동아리들이 운영되는 학생 자치 조직이다. 

문예, 체육, 사회, 학술, 종교분과 등 학생이 원하는 다양한 주제의 활동으로 동아리를 즐길 수 있다. 

대부분의 동아리는 학기 초에 진행되는 가두모집을 통해 신입생을 모집하므로,
